# 말하는 도감 — 동물 일러스트 스타일 가이드 (cute 그림체)

이 문서만 보고 남은 8종을 같은 그림체로 그릴 수 있게 정리했다. 기준 작품은 이미 완성된 4종(코끼리·곰·하마·캥거루)이다.
- 컬러와 그림자 비교 시트: `docs/silhouette_check/cute_trial.png`
- 그림자만 모은 시트: `docs/silhouette_check/cute_trial_shadows.png`
- 종별 코드: `tools/cute/species/<id>.py`

## 0. 절대 원칙

1. **오리지널만.** 외부 이미지, 기존 캐릭터, 특정 작품을 보거나 흉내 내지 않는다. 모든 path는 손으로 좌표를 잡아 쓴다.
2. **식별 특징은 바깥 윤곽에 걸린다.** 아이는 그림자만 보고 맞힌다. 다음 특징은 몸통과 겹치지 않게 실루엣 가장자리 밖으로 튀어나와야 한다.
   - 코끼리의 코, 기린의 목, 사자의 갈기, 토끼의 귀, 코뿔소의 뿔, 낙타의 혹, 원숭이와 캥거루의 꼬리
   - 몸 안쪽에만 있는 특징은 없는 것과 같다. `details`(컬러 전용)에만 넣은 특징은 그림자에 나오지 않는다.
3. **그림자는 컬러와 같은 소스에서 파생한다.** 그림자는 `shapes + accents + fillets`를 단색 `#1E1E1E`로 채운 것이다.
   - 그림자만을 위한 모양을 따로 그리지 않는다.
   - 컬러에만 있는 실루엣도 만들지 않는다.
4. **하나의 몸처럼.** 귀, 팔, 다리, 꼬리, 코는 몸에서 자라난 것처럼 이어져야 한다. 이 처리는 자동 필렛과 합집합 음영이 맡는다(§6).

## 1. 작업 방법 (병렬 작업 규칙)

- 내 종 파일 하나만 만든다.
  - `tools/cute/species/_template.py`를 복사해 `tools/cute/species/<id>.py`로 저장한다.
  - 파일 이름은 `ANIMAL["id"]`와 같아야 한다.
  - `species/` 폴더는 자동으로 탐색되므로 등록 절차는 없다.
- 다음 공용 파일은 **수정 금지**: `common.py`, `build.py`, `sheet.py`, 다른 종 파일.
  - 공용 기능이 꼭 필요하면 수정하지 말고 보고한다.
- 빌드와 확대 검사는 한 줄이다. 결과는 `<스크래치 폴더>/zoom_<id>.png`(컬러 | 그림자, 2048×1024)로 나온다.
  ```
  python3 tools/cute/build.py --only <id> --zoom <스크래치 폴더>
  ```
  - 출력 파일은 `assets/draft_silhouettes/cute/<id>_color.svg`, `<id>_shadow.svg` 두 개뿐이다. 다른 종 파일은 건드리지 않는다.
- 시트(`python3 tools/cute/sheet.py`)는 통합 단계에서 한 번만 돌린다. 각자 돌리면 같은 시트 파일을 서로 덮어쓴다.
- id와 도감 번호(`no`)는 다음과 같다(MASTER_PROMPT 순서).

| 2 | giraffe | 기린 | 8 | monkey | 원숭이 |

## 2. 캔버스와 배치

- viewBox는 `0 0 400 400`이다. 모든 내용은 x 20~392, y 16~368 안에 둔다.
- **바닥선:** 발바닥(또는 배·꼬리가 땅에 닿는 곳) y = **358 ± 8**이다. 완료 4종은 351~366.
- **바닥 그림자:** `ground=(cx, cy, rx, ry)`로 지정한다.
  - cy는 발바닥 y, ry는 8, rx는 몸 폭의 약 0.45배(135~160)로 한다.
  - 렌더 규칙(검정, opacity 0.08)은 공용 코드에 있다.
- **방향:** 모두 **왼쪽을 본다**. 펭귄만 정면이다.
- **크기:** 실루엣 경계 상자를 가로 230~370, 세로 280~345로 한다. 큰 동물과 작은 동물을 실제 크기 비율로 맞추지 않는다. 모두 칸을 비슷하게 채운다.
- **path 형식:** 절대좌표 `M`, `C`, `L`, `Z`만 쓴다. 필렛 계산기가 이 형식만 읽는다.
  - 상대명령(소문자), `A`, `Q`, `S`, `H`, `V`는 쓰지 않는다.
  - 숫자는 정수 또는 소수 1자리로 쓴다.
- `shapes`는 **뒤에서 앞 순서**로 나열한다. 먼 다리, 꼬리, 몸, 가까운 다리, 귀, 머리 순이다.

## 3. 비율 (등신)

- **아기 동물 비율:** 머리가 크고 몸은 작고 통통하며, 다리는 짧고 굵고 끝이 둥글다.
- **서거나 앉은 종**(곰, 캥거루, 토끼, 펭귄, 원숭이)
  - 머리 높이(귀 제외)가 전체 높이의 **40~50%**다.
  - 곰은 머리 167(귀 포함)에 전체 320, 캥거루는 머리 약 110에 전체 341(귀가 큼)이다.
- **네 발로 선 종**(하마, 코뿔소, 사자, 낙타)
  - 머리 높이가 몸통 높이의 **0.7~1.0배**다. 하마는 머리 190에 몸통 185.
  - 다리가 보이는 길이(배선부터 발바닥까지)는 30~60이다.
- **다리**
  - 폭 30~44, 발끝은 둥근 반원이다. `C` 두 개로 밑을 둥글게 닫는다.
  - **다리 사이 틈은 14 이상** 둔다. 그보다 좁으면 그림자에서 실금처럼 보인다.
- **허용하는 예외(과장)**
  - 기린: 목 길이가 머리 높이의 2~2.5배까지 된다. 전체가 3~3.5등신이 되어도 좋다. 머리 위 끝은 y ≥ 16.
  - 악어: 몸과 꼬리 길이가 머리 길이의 3배 이상이다. 높이는 낮게(실루엣 세로 110~150) 하고, 칸의 가로를 꽉 채운다.
  - 예외 종도 머리는 큼직하게, 눈은 같은 크기로 그린다. 그래야 같은 세트로 보인다.
- **모든 끝은 둥글게:** 뿔, 상아, 꼬리 끝, 발톱 모두 끝을 반지름 4 이상으로 둥글린다. 뾰족한 각은 없다.
- **최소 크기:** 튀어나온 특징은 두께 12 이상으로 한다. 120px 썸네일(축척 0.3)에서도 보여야 한다.

## 4. 얼굴

- **눈:** `eye(cx, cy, r)`를 쓴다.
  - r은 6.5~7이고, 세로 반지름은 1.15r이다. 색은 `#2B2420`이다.
  - 하이라이트는 흰 원(반지름 0.38r)을 (−0.35r, −0.45r) 위치에 둔다. 함수가 자동으로 그린다.
- **눈 위치**
  - 앞모습 3/4 얼굴: 두 눈 사이 간격 44~48, 머리 높이의 45~55% 지점, 왼쪽 눈이 주둥이 쪽이다.
  - 측면 얼굴(하마, 악어, 낙타, 사자, 코뿔소): 눈 하나.
- **볼터치:** `cheek(cx, cy, rx=11~13, ry=7~8)`를 쓴다. 색 `#F2A7A7`, opacity 0.55, 눈에서 30~40 아래 바깥쪽에 둔다.
- **코와 입**
  - 코: 작은 어두운 덩어리, `blob` 반지름 4~8.
  - 입: 3px 둥근 끝 선(`"stroke:#색"`). 색은 본체색을 어둡게 한 갈색이나 보라 계열이다.
  - 입은 작게 미소 짓는 정도로 하고, 크게 벌리지 않는다. 하마 하품은 악어와 혼동돼 폐기했다.

## 5. 색 (팔레트)

- **본체색은 파스텔 자연색**이다(대략 HSL 채도 20~50%, 명도 62~80%).
  - 완료 종: 코끼리 `#B8C4D0`, 곰 `#B98A63`, 하마 `#B7A6C9`, 캥거루 `#D9A577`.
  - 신규 권장값(조정 가능)

    | 종 | 본체 | 무늬·부분색 |
    |---|---|---|
    | 기린 | `#E8C27A` | 무늬 `#C9925A` |
    | 사자 | `#E3B676` | 갈기 `#C98A4E` |
    | 토끼 | `#EDE6DF` | |
    | 펭귄 | `#5C6B7E` | 배 `#F6F2EA`, 부리·발 `#F2B45C` |
    | 원숭이 | `#B88A68` | 얼굴 `#EBCBA8` |
    | 악어 | `#8DBE8A` | |
    | 코뿔소 | `#AEB1B5` | 뿔 `#D8D2C4` |
    | 낙타 | `#D8B07E` | |

- **부분색**
  - 배와 주둥이 밝은 부분: 크림 `#F3DDBE`, `#E8CBA8` 계열.
  - 귀 안쪽: `#F2B8A8`, `#F2C8CE`, `#E6A9B6` 중 하나.
  - 이빨과 상아: `#FFFDF6`.
- **본체색과 다른 실루엣 부위**는 `accents=[(path, color)]`에 넣는다. 예: 펭귄 부리·발, 코뿔소 뿔, 사자 갈기(본체와 색이 다르면). 그림자에는 포함된다.
- **외곽선(stroke)은 없다.** 선은 주름선(§6)과 details의 입·무늬 선뿐이다.

## 6. 음영·필렛·주름선 (공용 코드가 자동 처리)

- **음영 1단계:** 합집합 실루엣 전체에 한 번만 준다.
  - 본체색에 0.9를 곱한 어두운 색 위에, 본체색 사본을 `translate(-5 -6)`으로 밀어 덮는다(광원은 왼쪽 위).
  - 부위별로 음영을 따로 넣지 않는다. 이중 띠가 생긴다.
- **필렛(접합부)**
  - 부위 외곽이 만나는 모든 오목한 꺾임에 자동으로 곡선 쐐기를 채운다.
  - `r`은 기본 **10~13**이다(완료 종: 하마 10, 캥거루·코끼리 11, 곰 13).
  - 의도한 틈(겨드랑이, 팔과 몸 사이, 다리 사이)은 `r_pairs={(i, j): 3~5}`로 줄인다. 0이면 필렛을 넣지 않는다. 캥거루 앞발-몸이 `(2, 5): 4`.
  - 귀, 혹, 뿔의 **밑동은 머리나 몸 안쪽으로 깊이 넣어** 그린다. 밑동 끝점을 외곽 밖에 두면 갈고리 같은 꺾임이 생긴다.
- **주름선(creases)**
  - 끝이 열린 path 하나다. 공용 스타일은 본체색×0.84, 2.5px, opacity 0.6이다.
  - **앞 부위가 몸 위에 겹치는 곳만** 쓴다. 예: 팔 아랫선, 허벅지 윤곽 일부, 턱 아래선, 귀 앞선.
  - 한 종에 3개 이하로 한다. 부위 전체 외곽을 닫힌 선으로 따라 그리지 않는다. 그것이 '도형 조립' 느낌의 원인이다.
- **details**
  - 컬러 전용이다: 눈, 볼, 배, 귀 안쪽, 무늬, 입.
  - 면은 `(path, color, opacity)`, 선은 `(path, "stroke:#색", 1)`로 쓴다(3px, 둥근 끝).

## 7. 자세 배정표 (혼동 쌍을 갈라놓기 위해 확정)

| 종 | 자세 | 그림자 윤곽에 반드시 걸릴 것 |
|---|---|---|
| 코끼리 | 앞모습 3/4 선 자세, 코를 위로 말아 올림 | 머리 밖으로 올라간 코, 오른쪽으로 크게 펼친 귀, 짧은 기둥 다리 4개 |
| 곰 | 앞모습 3/4 앉음 | 머리 위 큰 둥근 귀 2개, 짧게 튀어나온 주둥이, 둥근 배, 앞으로 뻗은 발 |
| 하마 | 3/4 측면 선 자세, 입 닫음 | 높이가 큰 둥근 주둥이, 콧구멍 돌기 2개, 눈 돌기, 작은 귀, 통 몸, 짧은 다리 |
| 캥거루 | 앞모습 3/4, 꼬리를 땅에 대 지지하며 선 자세 | 세운 타원 귀, 끝이 둥근 주둥이, 가슴 앞 앞발, 긴 발, 굵고 긴 꼬리 |
| 기린 | 3/4 측면 선 자세 | 몸보다 높이 솟은 긴 목, 머리 위 뿔 2개(끝 둥근 혹), 긴 다리 |
| 사자 | 3/4 측면 선 자세 | 머리 윤곽 밖으로 크고 둥글게 부푼 갈기, 끝에 술이 달린 꼬리 |
| 토끼 | 3/4 앉음 | 머리 높이 이상으로 긴 귀 2개, 동그란 꼬리, 웅크린 둥근 몸 |
| 펭귄 | 정면 직립 | 몸 밖으로 벌린 날개 2개, 발 2개, 부리 |
| 원숭이 | 3/4 선 자세, 한 팔 들기 | 머리 양옆 귀, 위로 든 긴 팔, 몸 밖에서 말린 긴 꼬리 |
| 악어 | 완전 측면 엎드림 | 납작하고 긴 주둥이, 낮고 긴 몸과 꼬리, 등 위 작은 둥근 혹들, 짧은 다리 |
| 코뿔소 | 3/4 측면 선 자세, 입 닫음 | 주둥이 위 윤곽 밖으로 솟은 큰 뿔(+작은 뿔), 귀 |
| 낙타 | 측면 선 자세 | 등 위 혹 2개, S자로 굽은 목, 긴 다리 |

조정한 점과 이유:
- **캥거루:** 요청은 "앉아 꼬리 지지"였는데, 꼬리를 땅에 대고 **선** 자세로 확정했다.
  - 앉히면 큰 발과 긴 다리가 몸에 묻힌다.
  - 그러면 곰(앉음)이나 토끼(앉음)와 윤곽이 비슷해진다.
- **기린:** "선 자세"를 3/4 측면으로 구체화했다. 앞모습이면 목이 몸과 겹쳐 짧아 보인다.
- **사자·코뿔소·하마:** 셋 다 3/4 측면 선 자세다. 그래서 머리 윤곽 특징이 겹치지 않게 정했다.
  - 사자: 갈기가 머리를 둘러싼 큰 원이다.
  - 코뿔소: 뿔이 위로 솟는다.
  - 하마: 콧구멍·눈·귀 돌기 3단이다.
- **펭귄:** 유일한 정면이다. 정면이어야 벌린 날개 두 개와 발 두 개가 대칭으로 윤곽에 걸린다.

## 8. 혼동 주의 쌍과 가르는 윤곽 조건

| 쌍 | 가르는 조건 (그림자 기준) |
|---|---|
| 곰 - 사자 | 곰은 앉음, 머리 위에 따로 솟은 둥근 귀 2개, 꼬리 안 보임. 사자는 네 발로 섬, 귀는 갈기에 묻히고 머리 둘레가 둥근 갈기 덩어리(머리 폭의 1.5배 이상), 몸 뒤로 술 달린 긴 꼬리 |
| 하마 - 코뿔소 | 코뿔소는 주둥이 위에 높이 25 이상의 뿔이 윤곽 밖으로 나오고, 주둥이 끝이 좁아진다. 하마는 뿔 없음, 주둥이 끝이 넓고 둥글며, 머리 위가 콧구멍·눈·귀 작은 돌기로 오르내림 |
| 하마 - 악어 | 하마는 주둥이 높이가 길이의 0.7배 이상이고 끝이 둥글다. 몸이 높은 통이고 다리가 보인다. 악어는 주둥이가 납작하고 길며(높이 ≤ 길이의 0.35), 몸 전체 높이가 낮고 가로로 길다. 하마는 입을 크게 벌리지 않는다 |
| 토끼 - 캥거루 | 토끼는 웅크린 둥근 몸, 귀가 머리 높이 이상, 동그란 꼬리, 발이 몸 밑에 숨음. 캥거루는 몸을 세우고 귀는 머리 높이보다 짧다. 굵고 긴 꼬리가 땅까지, 긴 발이 앞으로 나오고 앞발이 보인다 |
| 낙타 - 기린 | 낙타는 등 위 혹 2개, 목이 앞으로 굽은 S자, 머리 높이가 혹과 비슷. 기린은 혹이 없고 목이 위로 곧게 길며 머리가 몸보다 훨씬 높다(목 길이 ≥ 몸통 높이). 머리 위 뿔 2개 |
| 원숭이 - 곰 | 원숭이는 귀가 머리 **양옆**, 팔다리가 길고 가늘며 한 팔을 위로 든다. 긴 꼬리가 몸 밖에서 말린다. 곰은 귀가 머리 **위**, 팔다리가 짧고 굵으며 꼬리가 안 보인다 |

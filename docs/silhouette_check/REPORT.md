## 3. 혼동 쌍 점검

| 쌍 | 결과 | 가르는 단서 |
|---|---|---|
| 곰 - 사자 | 구분됨 | 곰은 앉음 + 머리 위 둥근 귀. 사자는 네 발로 섬 + 갈기 + 술 꼬리 |
| 하마 - 코뿔소 | 구분됨 | 코뿔소는 윤곽 밖 뿔, 좁아지는 주둥이. 하마는 넓고 둥근 주둥이와 머리 위 작은 돌기 |
| 하마 - 악어 | 구분됨 | 하마는 높은 주둥이·통 몸·보이는 다리. 악어는 납작하고 긴 주둥이·낮고 긴 몸 (하품 폐기로 해결) |
| 토끼 - 캥거루 | 구분됨 | 토끼는 웅크린 몸·긴 귀·동그란 꼬리. 캥거루는 선 몸·긴 발·굵은 꼬리 |
| 낙타 - 기린 | 구분됨 | 낙타는 혹 2개 + 앞으로 굽은 목. 기린은 곧게 솟은 긴 목 + 뿔 |
| 원숭이 - 곰 | 구분됨 | 원숭이는 양옆 귀·든 팔·말린 꼬리. 곰은 위쪽 귀·짧은 팔다리·꼬리 안 보임 |

## 4. 남은 약점

- 악어: 다리가 짧아 그림자에서 배 밑의 홈처럼 보인다.
- 사자: 갈기 물결이 고르게 돌아가 해님처럼 보인다.
- 하마: 머리 외곽이 네모나게 보인다.
- 기린: 다리가 뻣뻣하고, 꼬리 밑에 작은 홈이 남아 있다.
- 토끼: 본체색이 밝아 배경과 대비가 약하다.
- 펭귄: 발 신호가 약하다.
- **아이 대상 실제 테스트는 아직 하지 않았다.** 위 판정은 제작자 눈 검사다.

## 5. 공용 코드 개선 과제 (`tools/cute/`)

- 레이어 순서: 머리를 감싸는 accent(사자 갈기)가 얼굴을 덮는다. accent를 머리 뒤에 둘 순서 지정이 필요하다.
- 필렛: 얕은 각도 접합부에서 실금이 생긴다.
- 중복 코드: `crocodile.py`, `monkey.py`에 `_tube`, `_smooth`, `_ell`이 복사돼 있다 → `common.py`로 옮긴다.
- 렌더 의존성: PNG 시트는 macOS `qlmanage`에 의존한다. Flutter SVG 렌더러 호환은 미확인이다.
